# Mineworld

浏览器中的 Minecraft 风格体素沙盒。当前还原目标为 **Minecraft Java 26.3 正式版**（2026-10-30 核对），不采用 26.4 快照。这是独立网页实现，不是原版 Java 客户端或其完整移植。

## 本轮已接入

- 官方客户端与资源索引中的方块、工具、食物、Steve 皮肤、水动画、HUD、容器、标题、全景和环境贴图。
- 原版字体字形、整数 GUI 比例、182×22 快捷栏、176×166 容器、Steve 背包角色预览及透明状态图层。
- 十种已适配生物的原版皮肤与模型：猪、牛、羊、鸡、僵尸、尸壳、骷髅、苦力怕、蜘蛛、兔子；兔子使用 26.3 的成人模型与跳跃/待机关键帧。
- 官方持物 display 参数、独立空手挥击、进食、拉弓、换物品下放/抬起和行走视角摆动；地面加速、惯性、空中控制、水中阻力及按住空格持续起跳。
- 攻击冷却与弱攻击、饱和回血、逐刻回气、现代潜行、方块光 0 刷怪门槛和树叶支撑距离 6。
- 新世界使用 26.3 原版密度/噪声、气候参数、地表和含水层配置，真实高度 -64…319、海平面 63、完整有符号 64 位种子。基础树木和煤铁金钻矿脉可采集；深板岩、凝灰岩、陶瓦等方块有实际材质与物品。
- 橡树、白桦和两种云杉树形按 26.3 树冠规则生成；草甸、平原、森林、针叶林与荒地使用不同草花配置。新增 12 种花、蕨和枯灌木，支持透明模型、手持图标、花朵采集与土壤放置。
- 皮革、铁、金、钻石四套护甲：四个可操作装备槽、角色预览、护甲值、减伤、耐久、合成、死亡掉落与存档；金锭和粗铁/粗金冶炼链。

现有世界的种子、方块 ID 和编辑差量保持兼容。最早的旧世界保留原生成器与 0…191 高度；上一轮现代世界也保留 `java26` 生成结果。本轮新世界使用 `java26v2`，已有世界不会重生成；请创建新世界体验新的树林和草花（草甸示例种子 36、针叶林 29）。第一次加载新版会将旧画面预设切到原版材质与基础光照，之后保留手动选择。

## 明确尚未完成

并非所有画面和机制已逐帧一致。50 个独立原版样本的群系/密度符号相同、密度误差小于 0.000003，不代表整张地图同种子逐方块一致。小树树冠形状已用独立原版 Java 输出核对，但树木、草花和矿脉的位置仍是近似算法，尚缺完整结构/装饰系统、群系缩放、地形雕刻器、恶地彩带与大矿脉。下界仍使用旧生成器。

尚缺完整方块/物品库、红石、副手、附魔、经验、配方书、完整游泳/爬行、末地和原版服务器协议。护甲未覆盖锁链/下界合金、纹饰与附魔。物品立方体图标由原版面纹理投影，部分方块仍使用简化几何；草叶暂用代表性着色。生物 AI、动作触发、天空光照和日月轨迹还需要继续对照。月亮使用原版满月图，尚无八天月相状态。

## 开发与验证

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run preview
```

生产路径 `/mineworld/`。GitHub Actions 的 `Deploy to GitHub Pages` 工作流负责发布。

素材来源与哈希在 `public/textures/java-resource-provenance.json`、`public/textures/ui/java/provenance.json`、`public/textures/environment/provenance.json` 和 `public/textures/mobs/SOURCES.json`。Minecraft 美术资源归 Mojang AB / Microsoft；不会将它们标为 Mineworld 原创。资源适配脚本在 `tools/textures/`，不会将完整客户端或游戏执行代码打包发布。

规则、动作、护甲与生成核对细节见 `docs/survival-audit.md`、`docs/first-person-26.3-audit.md`、`docs/armor-audit.md` 和 `src/core/worldgen/modern-worldgen.md`。地图数据适配使用 MIT 许可的 Deepslate 0.27.2，详细来源及原版数值基准随项目保存。
